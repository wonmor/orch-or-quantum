# orch-or-quantum

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23149128.svg)](https://doi.org/10.5281/zenodo.23149128)

Density-matrix and quantum-circuit simulations of Orch-OR dynamics on a chain of tubulin qubits, with the
Diósi–Penrose self-energy calibrated to Hameroff & Penrose (2014), environmental dephasing at the Tegmark and
Hagan et al. rates, jump and continuous readings of objective reduction, and a Trotterised Qiskit circuit under
a calibrated IBM Heron noise model with full Pauli tomography.

Paper: `paper/orch-or-qubits.pdf`. Every number in it is generated by `scripts/make_figures.py` into
`results/macros.tex`, which the manuscript includes.

## Reproduce
```bash
python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/e1_scaling.py       # OR interval vs N            (~15 min)
.venv/bin/python scripts/e2_decoherence.py   # event rate vs gamma, N=6    (~10 min)
.venv/bin/python scripts/e3_unravelling.py   # jump vs continuous, N=6     (~5 min)
.venv/bin/python scripts/e4_circuit.py       # Qiskit Aer + FakeTorino noise, tomography (~5 min)
.venv/bin/python scripts/make_figures.py     # figures/ and results/macros.tex
cd paper && pdflatex orch-or-qubits.tex && pdflatex orch-or-qubits.tex
```
To run the circuits on real IBM hardware, save an account with `QiskitRuntimeService.save_account(...)` and
replace `AerSimulator.from_backend(fake)` in `scripts/e4_circuit.py` with a `QiskitRuntimeService().backend(...)`.

## Model in one paragraph
Qubit *i* is tubulin *i* (|0⟩ = conformation A, |1⟩ = B). Orchestration is a transverse-field Ising chain
H/ħ = −J ΣZZ − h ΣX. The number of tubulins in coherent superposition is M(ρ) = Σ_i 2‖ρ^(i)_01‖₁ (trace norm of
the off-diagonal bit-i block), which equals N for both |+⟩^N and GHZ_N and 0 for any classical mixture.
E_G = ε_q M with ε_q = ħ/(25 ms × 2×10¹⁰) × (tubulins per qubit). Jump rule: collapse to a sampled bitstring
when ∫E_G dt ≥ ħ. Continuous rule: ρ_ab ← ρ_ab exp(−(ε_q/ħ) d_H(a,b) dt). Environmental dephasing:
ρ_ab ← ρ_ab exp(−γ d_H(a,b) dt).
